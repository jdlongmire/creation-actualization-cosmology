# Agent Profiles

Role definitions for research assistance on this programme. Invoke the profile whose
trigger matches the work; the profiles exist so that a reviewing role cannot quietly
become a producing role.

| Profile | Trigger |
|---|---|
| [red-team-reviewer.md](red-team-reviewer.md) | Any new belt claim, any candidate discriminator, any promotion of an accommodation to a prediction |
| [exegesis-reviewer.md](exegesis-reviewer.md) | Any change to a `HER-*` claim or to `2-theory/00-exegesis/` |

## Standing rule for all profiles

**A reviewing role does not produce the artifact it reviews.** The pattern this guards
against is well documented in the sibling TRT programme, where producer-side conclusions
were twice overturned by an independent red-team within the same session — in both cases
because the producer had over-read its own result. The gate only works if the reviewer
did not write the thing.
