# Session Journal

One file per working session, named `YYYY-MM-DD-topic.md`. Appended at wrap, after
`research-wrap.py` passes.

The journal is the programme's narrative record; the
[appraisal log](../../3-prediction/appraisal.md) is its epistemic record. Keep them
distinct. A session that produced no epistemic change still gets a journal entry, and
that entry says so.

## Shape

```markdown
# YYYY-MM-DD — <topic>

## What was attempted
## What was found
## Effect on the appraisal   (usually: none — say so plainly)
## Carry forward
```

The **Carry forward** section is read back by `research-start.py` at the next session.
Anything not written there is not carried.
